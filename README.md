# Mlýn Kasárníkův – Jemnice (web)

Jednoduchý statický web pro **Mlýn Kasárníkův v Jemnici** pojatý jako **webová kronika**:
- historie mlýna (archivní fotografie)
- průběh rekonstrukce (kronika / příspěvky)
- galerie
- kontakt / poptávka

Web je postavený čistě pomocí **HTML + CSS + JavaScript** (bez frameworků).
